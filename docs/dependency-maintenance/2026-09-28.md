## Repairs and security coverage

`LinkedAccountsActivity` now registers `OpenPlaidLink`, creates a single-use `PlaidLinkSession`, supplies `onLoad` in the token configuration, and destroys the owned session on result, timeout, cancellation, and Activity destruction. Preload waits in the lifecycle coroutine, so a late callback cannot open a timed-out/destroyed activity. The 30-second deadline, safe error messages, provider cancellation, token exchange, and reconnect handling remain. Removed the obsolete global `Plaid.destroy`, handler API, and `logLevel` setting (v6 has no replacement). No SDK events or provider payloads are logged by application code.

The first full gate exposed 14 new lint errors. Date/day formatting now reads Compose LocalLocale so language changes trigger recomposition; the error dialog observes repository StateFlow via collectAsState. Transitive Fragment versions are constrained to 1.9.1 instead of suppressing the Activity Result compatibility check. Shared Compose BOM and Activity catalog entries now serve both modules.

GitHub initially reported zero Dependabot alerts and zero open secret-scanning alerts. However, the exported dependency graph contained only six GitHub Actions dependencies plus the repository, with no Android artifacts. Added the official Gradle dependency-submission action on main pushes to submit resolved dependencies for future vulnerability alerts, with GitHub-backed basic caching and wrapper checksum validation. A direct GitHub Advisory Database check of 196 resolved runtime coordinates found Guava 31.1-android matching GHSA-5mg8-w23w-74h3 (low, temporary-directory information disclosure) and GHSA-7g45-4rm6-3mm3 (medium, insecure temporary-file use). Added a 33.7.1-android minimum constraint to remove both matches. This is a preventive dependency fix; no exploitation is claimed. An OSV POST was rejected by automatic approval review for third-party metadata egress; the audit used GitHub GET queries instead. The final resolved-runtime rescan is recorded below; the new submission workflow and resulting GitHub alert state are checked after pushing main and before tagging.

The January 2026 Gradle advisories GHSA-mqwm-5m85-gmcv and GHSA-w78c-w6vf-rw82 affect versions before 9.3.0 on the 9.x line; neither the previous nor selected wrapper is affected. Plaid reports security improvements without a published CVE/GHSA in its repository. Zero alerts does not establish the absence of undisclosed vulnerabilities.

The first main push passed Android CI and successfully submitted 381 graph packages, including 373 Maven coordinates. That broader inventory exposed eight previously invisible **build-tool** alerts, so the release tag was held for a second security repair. These libraries are brought in by AGP, bundletool, Jetifier, and standalone tooling configurations; they were absent from the clean 193-coordinate app runtime inventory. Maven Central and upstream release/advisory records were checked before selecting the following compatible-line updates:
