## Findings

- **F1 — Long timer clipping (P2): closed after final verification.** Exercise validation accepts every positive Int duration. The new large, single-line clock could exceed the card width for values such as `2147483647` seconds (`35791394:07`), leaving digits or Start inaccessible. The timer panel now measures the complete clock, scales it only when required to fit, and places Start below clocks longer than five characters. The timer value, reducer, countdown and persistence are unchanged. A maximum-duration unit regression and four native boundary references cover this case.
- **F2 — Set heading crowding (P2): closed after final verification.** Four to six 24 dp indicators with 12 dp gaps previously shared one compact row with the set label and 48 dp overflow. At six sets they consumed 204 dp before the label or overflow. More than three indicators now move below the set label. Four new six-set references cover compact, tall, 2x font and landscape layouts.
- **F3 — Dashboard query stale across midnight (P2): closed after final verification.** Dashboard's date ticker moved to the next date, but the parent health query refreshed only on route/range/focus changes. A continuously foregrounded Dashboard therefore kept the previous day's query window. The existing foreground loop now compares the active health window every two seconds and refreshes when its civil date changes. A year-boundary window regression supplements the range-isolation tests. This does not write or change the metric-detail range preference.
