# DR5-055 widget integration evidence

The provider maps the 50 approved `widget_01_dumbbell`–`widget_50_curtain_call` WebPs in catalog order. A focused SHA-256 and byte-size comparison against `docs/design/widget-icon-variants/batches/all-50-measurements.json` found 50 resources, 50 matches, no extra numbered runtime WebPs, and 693,818 total bytes. The old four prototype WebPs are no longer runtime resources. `RemoteViews.setImageViewResource` gives the host each WebP's actual alpha: no circular bitmap mask is applied. The existing launcher icon resources were not edited.

The look is selected from the current UTC hour modulo 50. All installed widgets receive the same deterministic look, including after process death or launcher recreation; skipped host callbacks skip looks rather than accumulating work. Android owns the inexact 3,600,000 ms update period. App entry, widget resize options, boot, time correction, package replacement, and widget restore also refresh installed instances. No service, wake lock, precise alarm, or polling loop was added. App entry with no installed widget returns before resource work.
