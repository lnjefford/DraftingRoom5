# Round-first H2 launcher icon

The launcher icon uses the selected H2 design: a black background, the ivory measured 5 with three gold notches, and a complete gold circular ring with two short hatched sections. The in-app framed mark and the separate notification silhouette remain unchanged.

The numeral uses the same path as the in-app mark. Its launcher width is 37.13 units, up from 29.36 units in the prior framed launcher icon. The ring's 32-unit radius and 2-unit stroke reach, but do not exceed, Android's guaranteed 33-unit safe radius. Static square, legacy round, adaptive, adaptive round, and API 33 themed resources point to the new vector pair.

[`launcher-h2/mask-review.png`](launcher-h2/mask-review.png) shows the selected design under circle, squircle, rounded-square, and tight masks in full color and themed monochrome. The contact sheet was generated by [`render_mask_review.py`](launcher-h2/render_mask_review.py) from the selected vector geometry at the same 108-unit viewport and inspected at 48-pixel home-screen size. It is host-rendered mask evidence; actual OEM launcher rendering remains a device check.

The focused `MeasuredFiveAssetTest` run passed. The full `:app:testDebugUnitTest :app:lintDebug :app:assembleDebug` gate then passed on 2026-09-13 with no failures. `git diff --check` found no whitespace errors. The build used a temporary output directory because the existing OneDrive-managed `app/build` tree was read-only.
