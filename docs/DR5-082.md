# DR5-082 — Optional post-exercise adjustment

Guided-session UI and lifecycle handoff for Phase 10. This work remains local
with the accumulated DR5-080/081 changes and does not publish a release.

## Completion behavior

- Completing an exercise opens a compact sheet with filled **Next exercise**
  first and outlined **Adjust exercise** second. Next records the handled
  completion, changes no prescription, consumes no planned step, and reveals
  the next exercise that the committed set event already focused.
- The root sheet contains no target controls. Adjust first shows a complete
  current Weight/Duration/Sets/Reps card and the exact next planned replacement
  plus inserted exercises when one exists. Manual-only exercises receive the
  same completion sheet.
- Applying the planned step uses the repository's atomic custom request: one
  complete prescription replaces the source, exactly one queue item is
  consumed, additions are inserted once, and Undo restores both source and
  additions.
- Manual adjustment exposes independent Weight, Duration, Sets, and Reps
  steppers and an exact resulting-prescription preview. One save can change all
  four fields. Weight has no free-form entry and moves only by 5 lb; the same
  domain validation rejects malformed, zero, negative, or non-multiple values
  before persistence. Manual save preserves the entire planned queue and is
  undoable.

## Lifecycle, race, and accessibility evidence

Sheet mode and primitive drafts are saveable UI state only. Back from manual
returns to the prescription review, Back from review returns to completion, and
root dismissal uses keep-current; none of those paths calls progression apply.
Codec recreation retains an unhandled manual-only offer without applying data.
Repository tests cover failed-write atomicity, stale routine and session
revisions, revoked leases, competing manual/custom decisions, duplicate taps,
process restart, insertion lineage, queue preservation, and Undo expiry.

The Android native audit now checks the TalkBack order and labels for Next,
Adjust, current prescription, planned prescription/additions, four manual
controls, result preview, safe Back, multi-target save, preserved queue, and
Undo. Android-test sources compile, but `adb devices -l` reported no attached
device, so native TalkBack execution is not claimed as passing.
