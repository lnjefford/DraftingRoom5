# DR5-081 — Structured exercise and planned-progression editors

Compose implementation and visual-validation handoff for Phase 10. This item
does not implement the post-exercise adjustment flow owned by DR5-082 and does
not publish a release.

## Editor behavior

- Weight, Duration, Sets, and Reps are independent first-class targets. Weight
  is optional and its only editing actions move exactly 5 lb; an unset target
  starts at 35 lb. Duration is optional and is the exercise timer itself. Sets
  remain required; reps are optional. Clear actions remove optional targets.
- Name, notes, paired artwork, validation, save/discard handling, natural focus
  order, and saveable primitive/editor state remain intact. Cancel and system
  back use the same unsaved-change protection.
- The subordinate Planned progression section is optional, summarizes the next
  complete prescription, and opens its ordered editor. Disabling it saves no
  progression while retaining the in-memory queue if the user turns it back on
  before saving.
- Future steps edit the complete prescription through the same target controls.
  Each list card shows its full result and exact changes from the immediately
  preceding prescription. Reordering recalculates that baseline. Add, edit,
  delete, drag, Ctrl+arrow, TalkBack reorder actions, inserted exercises, and
  nested exercise name/notes/artwork behavior remain available.
- Automatic progression, Rest between sets, and the After each exercise card
  are absent. New fixtures use 35, 40, and 45 lb.

## Accessibility and visual review

The native progression audit now mounts the production exercise editor and
asserts all four target actions, Planned progression, an exact 35 → 40 lb
accessibility action, and absence of the three removed concepts. Android-test
and screenshot-test sources compile. No Android device was attached, so the
native audit was not executed and is not reported as passing.

Eight intentional reference PNGs were inspected individually: compact, tall,
landscape, and 2× large-text variants for both the structured exercise editor
and ordered progression editor. The dark quiet hierarchy, 48 dp actions,
35/40/45 lb examples, wrapping, scroll continuation, and exact before/after
copy are legible. No horizontal clipping, overlapping controls, obsolete
37.5 lb example, automatic-progression copy, or unintended reference change
was accepted. Short landscape captures intentionally show the scrollable top
portion rather than compressing the form.
